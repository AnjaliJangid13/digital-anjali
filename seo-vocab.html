SEO Vocabulary

Learn the most important SEO terms and concepts used in search engine optimization and digital marketing. This SEO vocabulary guide explains common terms in simple language.

1. SEO

SEO stands for Search Engine Optimization. It is the process of improving a website so that search engines can understand its content and users can discover it through organic search results.

2. On-Page SEO

On-Page SEO refers to optimizing elements present on a webpage, such as content, headings, URLs, title tags, meta descriptions, images and internal links.

3. Off-Page SEO

Off-Page SEO includes activities performed outside a website to improve its visibility and authority. Link building, brand mentions and content promotion are common examples.

4. Keyword

A keyword is a word or phrase that people type into search engines when looking for information, products or services.

5. Keyword Research

Keyword research is the process of finding relevant search terms that can help you understand what your target audience is searching for.

6. Long-Tail Keyword

A long-tail keyword is a more specific search phrase containing several words. These keywords often target a narrower search intent.

7. Title Tag

A title tag is an HTML element that describes the main topic of a webpage. It can appear as the clickable title of a page in search results.

8. Meta Description

A meta description is a short HTML description that summarizes the content of a webpage. Search engines may display it below the page title in search results.

9. H1 Heading

The H1 heading generally represents the main heading of a webpage. It helps users and search engines understand the primary topic of the page.

10. H2 Heading

H2 headings are used for major sections within a page. They make long content easier to scan and organize.

11. Internal Linking

Internal linking means linking one page of a website to another page on the same website. It helps visitors navigate related content and helps search engines discover pages.

12. Backlink

A backlink is a link from another website to your website. Relevant and naturally earned links can help search engines understand the authority and relevance of a website.

13. Anchor Text

Anchor text is the clickable text used for a hyperlink. It gives users and search engines context about the page being linked to.

14. Alt Text

Alt text is an HTML attribute used to describe an image. It can improve accessibility and help search engines understand image content.

15. Canonical Tag

A canonical tag tells search engines which version of a page should generally be treated as the preferred or canonical URL when similar versions exist.

16. XML Sitemap

An XML sitemap is a file that provides search engines with information about important URLs on a website. It can help search engines discover website pages.

17. Robots.txt

Robots.txt is a file that provides instructions to search engine crawlers about which areas of a website they may or may not access.

18. SERP

SERP stands for Search Engine Results Page. It is the page displayed by a search engine after a user enters a search query.

19. Organic Traffic

Organic traffic refers to visitors who reach a website through unpaid search engine results.

20. Search Intent

Search intent is the reason behind a user's search. Understanding intent helps you create content that matches what people actually want to find.
